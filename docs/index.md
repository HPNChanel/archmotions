## What is ArchMotion?

ArchMotion is a **Code-to-Video Framework** for system architecture animations.
Write Python code describing your architecture → Get a professional MP4 video.

## Core Concepts

1. **Primitives**: Node, Database, Connection — the building blocks
2. **Animations**: FadeIn, FadeOut, Transfer, Pulse — the effects
3. **Timeline**: Sequential and Concurrent execution control
4. **Render**: Zero-Disk I/O pipeline producing 1080p/60fps video
